# MCP-сервер для Autodesk Revit

Связка из двух частей, которая позволяет ИИ-ассистенту (Claude Desktop, Claude Code и любому
другому MCP-клиенту) работать с открытым проектом Revit: подключать облака точек, поднимать
по ним модель и выпускать комплект чертежей по заданному шаблону.

```
MCP-клиент ──stdio──► mcp-server (Python)  ──HTTP 127.0.0.1:8765──►  McpRevit.dll (аддин)
                                                                       │
                                                                       ▼
                                                            Revit API (UI-поток)
```

Revit API можно вызывать только из потока пользовательского интерфейса, поэтому аддин принимает
HTTP-запрос в фоновом потоке и через `ExternalEvent` передаёт работу в Revit, дожидаясь результата.

Поддерживаются **Revit 2023, 2024, 2025, 2026**. Все размеры на входе и выходе — миллиметры.

## Что умеет

**Облако точек**
- подключение `.rcp` / `.rcs` со смещением и поворотом;
- выборка точек с автоподбором плотности и ограничением области;
- обзор облака: габариты и распределение точек по высоте (пики = полы и потолки);
- поиск плоскостей методом RANSAC с уточнением по МНК — с разделением на горизонтальные,
  вертикальные (со следом стены в плане) и наклонные.

**Модель**
- уровни по горизонтальным плоскостям облака;
- стены по вертикальным плоскостям, с выравниванием осей по ортогональной сетке;
- стены по произвольным осевым линиям, перекрытия по контуру, соединение стен.

**Чертежи**
- планы, потолочные планы, разрезы, фасады, 3D-виды;
- листы по JSON-шаблону: нумерация, имена, штамп, автоматическая раскладка видов;
- выгрузка в PDF и DWG.

## Быстрый старт

1. Соберите и установите аддин (Windows, установленный Revit):

   ```powershell
   .\scripts\install-addin.ps1 -RevitVersion 2023
   ```

2. Установите MCP-сервер:

   ```powershell
   py -3.11 -m venv .venv
   .\.venv\Scripts\pip install -e .\mcp-server
   ```

3. Пропишите сервер в MCP-клиенте — см. `examples/claude_desktop_config.json`.

4. Запустите Revit, откройте проект. На вкладке **MCP** проверьте, что мост в состоянии
   «работает», и спросите ассистента: *«проверь связь с Revit»*.

Подробности — в [docs/INSTALL.md](docs/INSTALL.md).

## Типовой сценарий обмерных работ

```
Подключи облако точек C:\Scan\dom.rcp
Покажи распределение точек по высоте
Создай уровни по облаку
Построй стены первого этажа по облаку с выравниванием по 90°
Выпусти комплект по шаблону obmer-ar в папку C:\Revit\Выгрузка
```

Файлы `.e57`, `.las`, `.pts` Revit напрямую не принимает — сконвертируйте их в Autodesk ReCap
в формат `.rcp`/`.rcs`.

## Структура

| Путь | Назначение |
| --- | --- |
| `revit-addin/` | Аддин Revit (C#): HTTP-мост и команды поверх Revit API |
| `mcp-server/` | MCP-сервер (Python): инструменты и движок шаблонов |
| `templates/` | Шаблоны комплектов чертежей (JSON) |
| `examples/` | Примеры конфигураций MCP-клиента и аддина |
| `scripts/` | Сборка и установка аддина |
| `tests/` | Тесты Python-части (Revit не требуется) |

## Тесты

```bash
python -m venv .venv && .venv/bin/pip install -e ./mcp-server pytest
.venv/bin/python -m pytest tests -q
```

Тесты работают без Revit: мост подменяется поддельным транспортом, поэтому проверяются
и разбор шаблонов, и вся цепочка выпуска листов.

## Безопасность

Мост слушает только `127.0.0.1` и по умолчанию работает без авторизации, полагаясь на то, что
доступ к порту есть лишь у локальных процессов. Если на машине работают недоверенные пользователи
или программы, задайте общий секрет в `mcp-revit.config.json` (`token`) и в переменной окружения
`REVIT_BRIDGE_TOKEN` у MCP-сервера. Токен должен состоять только из ASCII-символов.

Команды моста меняют модель. Изменения выполняются в транзакциях Revit, поэтому их можно
отменить через `Ctrl+Z`, но перед массовыми операциями лучше сохранить проект.
