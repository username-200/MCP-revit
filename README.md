# MCP для Autodesk Revit

Обвязка вокруг плагина [LuDattilo/revit-mcp-server](https://github.com/LuDattilo/revit-mcp-server):
инструкция по установке, шаблоны комплектов чертежей и сохранённые наработки по
обмеру, которых в самом плагине нет.

```
MCP-клиент ──stdio──► mcp-server-for-revit (Node) ──TCP 8080──► RevitMCPPlugin.dll
                                                                      │
                                                                      ▼
                                                                 Revit API
```

Собственный HTTP-мост, живший здесь раньше, удалён: его заменил плагин LuDattilo
со 124 инструментами и поддержкой Revit 2023–2027. История прежней реализации
осталась в git.

## Начало работы

1. Снимите прежний аддин: `.\scripts\uninstall-addin.ps1` (Revit должен быть закрыт).
2. Установите плагин и подключите клиент — [docs/SETUP.md](docs/SETUP.md).

## Состав репозитория

| Путь | Назначение |
| --- | --- |
| `docs/SETUP.md` | Установка плагина, подключение клиента, диагностика |
| `docs/TEMPLATES.md` | Формат JSON-шаблона комплекта чертежей |
| `templates/` | Шаблоны комплектов: `obmer-ar`, `plany-po-etazham` |
| `porting/` | Наработки по облакам точек и шаблонам под перенос на команды плагина |
| `scripts/uninstall-addin.ps1` | Удаление прежнего аддина MCP Revit Bridge |

## Про облака точек

Плагин не умеет работать со сканами: среди его инструментов нет ни подключения
`.rcp`/`.rcs`, ни детекции плоскостей, ни построения стен по облаку. Обмерный
сценарий на нём напрямую не собирается.

В [porting/](porting/README.md) сохранены рабочие части прежней реализации —
RANSAC-детектор плоскостей на C#, движок шаблонов чертежей на Python и эвристика
деления стен на наружные и перегородки. Переносятся они через
`send_code_to_revit` либо добавлением своей команды в `commandset/` плагина.

## Тесты

Движок шаблонов проверяется без Revit:

```bash
python -m pytest porting/sheet-templates -q
```

## Безопасность

Плагин исполняет команды на живой модели, а `send_code_to_revit` — произвольный C#
внутри Revit. Работайте на копиях проектов и проверяйте пакетные операции до
запуска.
